⚠️ Zone de danger

⚠️ Suppression définitive

Attention !

Cette action supprimera définitivement :
  • Tes données personnelles (prénom, texte)
  • Tes contacts d'urgence
  • Tes informations médicales
  • Tous tes paramètres de contextes
  • Ton journal de crises
Cette action est irréversible.

💡 Tu peux d'abord sur ton appareil avant de continuer.

📤 Exporter mes données

L'export va créer un fichier de sauvegarde contenant toutes tes informations (profil, contacts, carte d'urgence, paramètres, journal de crises).

Ce fichier sera téléchargé sur ton appareil. Tu pourras l'utiliser pour :
  • Sauvegarder tes données en lieu sûr
  • Les transférer sur un autre appareil
  • Les restaurer si tu réinitialises l'app
Tes données restent intactes sur cet appareil.

📥 Importer des données

L'import va remplacer toutes tes données actuelles par celles du fichier de sauvegarde.

⚠️ Attention : cette action est irréversible. Toutes tes données actuelles seront écrasées par le contenu du fichier importé.

Assure-toi d'importer un fichier exporté depuis Nora.
