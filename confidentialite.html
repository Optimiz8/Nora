Confidentialité

🔒 Politique de confidentialité

🛡️ Toutes tes données restent sur ton téléphone. Rien n'est envoyé vers un serveur, une base de données ou un service tiers.

Quelles données sont stockées ?

Nora stocke localement sur ton appareil :

  • Ton prénom et nom (optionnel)
  • Tes contacts d'urgence (nom, téléphone, lien)
  • Tes informations médicales (groupe sanguin, allergies, traitements…)
  • La configuration de ta carte d'urgence numérique
  • Tes cartes de communication personnalisées
  • Tes paramètres de contextes
  • Ton journal de crises
  • Tes ambiances sonores (préréglages mixeur et volumes)
  • Ta playlist musicale
  • Tes préférences d'affichage (timer, son…)
Où sont-elles stockées ?

Toutes les données sont enregistrées dans le LocalStorage de ton navigateur, sur ton appareil uniquement. Il s'agit d'un espace de stockage local qui ne communique pas avec internet.

Qui peut y accéder ?

Aucun serveur, aucune personne tierce, aucune analytics, aucun cookie de traçage n'est utilisé.

Les données sont stockées en clair dans le navigateur. Toute personne ayant accès à ton appareil déverrouillé et à ce navigateur peut techniquement les lire (via les outils de développement). Verrouille ton écran pour protéger l'accès.

Désinstaller vs supprimer les données

Si tu désinstalles l'application (appui long sur l'icône → "Désinstaller") :

  • Sur iPhone/iPad : les données sont supprimées avec l'application.
  • Sur Android : les données sont généralement supprimées avec l'application.
  • En cas de doute, exporte tes données avant de désinstaller (Paramètres → Données → Exporter).

Pour effacer tes données sans désinstaller : Paramètres → Données → Réinitialiser les données.

Supprimer le raccourci de l'écran d'accueil sans désinstaller ne supprime pas tes données — tu peux réinstaller Nora et les retrouver intactes.

Export et partage

L'export crée un fichier JSON sur ton appareil. Tu es seul·e responsable de la sécurité de ce fichier. La carte d'urgence peut être partagée via QR Code — dans ce cas, les informations de la carte sont accessibles à quiconque scanne le code.

Mise à jour de cette politique

Cette politique peut être mise à jour lors des nouvelles versions de l'application. La version actuelle est indiquée dans "À propos de Nora".
